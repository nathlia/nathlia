### ✦ Featured project

**[govbr-ds-validator](https://github.com/nathlia/govbr-ds-validator)**: a TypeScript **Model Context Protocol** server that AI agents use to validate interfaces against about 3,000 gov.br design system, e-MAG and WCAG rules. It opens the page with **Playwright**, measures colors, sizes, structure and accessibility with **axe-core**, and double-checks every finding before the agent reports it. It also runs a with/without-tool experiment on GitHub Actions to see whether the tool really helps.

> e.g. dialog text in `#334333` instead of the design system's `#333333`. You can't see the difference, and the agent alone missed it 3/3 times. With the tool, it caught it 3/3.
